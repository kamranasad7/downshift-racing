# Music track sources (pick 1-2, ~5 min)

Browse, pick something driving/upbeat that fits a downhill run, download the mp3/ogg, drop it in a folder and tell Claude — it gets wired into the music slot with the MUSIC toggle already built.

1. **Pixabay Music** — https://pixabay.com/music/ — search "driving rock", "energetic chase", "adventure upbeat". License: Pixabay Content License (free, commercial OK, no attribution). Easiest browse experience.
2. **incompetech (Kevin MacLeod)** — https://incompetech.com/music/royalty-free/music.html — filter Feels: Driving/Intense. License: CC-BY 4.0 (requires a credits line in the game — fine; a credits entry gets added when chosen).
3. **OpenGameArt** — https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=12&sort_by=count&sort_order=DESC — filter license CC0. Game-focused loops, quality varies.

Note: FreePD.com has shut down (verified 2026-07-23) — ignore old links to it.
